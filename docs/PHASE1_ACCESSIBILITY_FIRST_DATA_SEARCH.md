## New high-priority direct historical-access candidates

### 1. Exact MSCI equity index **levels**, not constituents

- **Public JSON levels route**, independently documented in [NikhilSuthar/indian-market-data mscidata/fetcher.py](https://github.com/NikhilSuthar/indian-market-data/blob/main/packages/msci-data/src/mscidata/fetcher.py): `https://app2.msci.com/products/service/index/indexmaster/getLevelDataForGraph`, GET with query `index_codes=892400&currency_symbol=USD&index_variant=NETR&data_frequency=DAILY&start_date=20260101&end_date=20261001`. The author documents the `indexes.INDEX_LEVELS[]` response fields `calc_date`, `level_eod`; no API key; 2000-01-01 alleged earliest history. An unauthenticated historical index **series** is a materially stronger candidate than factsheets or ETF proxies. **Provider API response, data span and missingness not independently checked**. The code's exact key `892400` is confirmed by MSCI's [ACWI original index page](https://www.msci.com/indexes/index/892400/msci-acwi-index). MSCI World is `990100`, MSCI Emerging Markets is `891800`, per MSCI original index tables.
- **Convenience package:** [msci-data PyPI](https://pypi.org/project/msci-data/) / [README](https://github.com/NikhilSuthar/indian-market-data/blob/main/packages/msci-data/README.md), `msci.get_levels("892400", "2000-01-01", "2026-10-01", variant="NETR")` (conceptual example; requires live verification, and date-span data may be truncated or unavailable). NETR is net-of-withholding-dividend-reinvestment return index **levels**, not the actual original constituent history.
- **Original official MSCI index page** also shows current top 10 and country/sector weights. Historical index-level returns, fund holdings, and historical constituent weights are three distinct research objects. **Public levels do not deliver index constituents.**
- **Source terms:** website notices restrict various copying and automation; user asked to include publicly reachable data regardless in the *research inventory*. Record restrictions as metadata but do not misclassify a publicly reachable source as technically unavailable merely because it has restrictions. This research item does not attest to a lawful right of redistribution.

### 2. Historical iShares ETF/UCITS holdings as-of date

- [talsan/ishares](https://github.com/talsan/ishares) provides an original provider AJAX history downloader using historical `asOfDate=YYYYMMDD`, with [README](https://github.com/talsan/ishares/blob/master/README.md) documenting source data as early as **2006-09-29 for certain US iShares funds**, CSV columns including ISIN, SEDOL, shares, market value and weight, and arbitrary historical query dates.
- [Historical endpoint discovery note](https://gist.github.com/dachent/a80848d89966daa6730cd553be691b1a) shows `https://www.ishares.com/{product_url}/1467271812596.ajax?fileType=json&tab=all&asOfDate=YYYYMMDD` with `fileType=csv` as another supported format.
- **Specific UCITS test:** [SWDA/iShares Core MSCI World UCITS](https://www.ishares.com/uk/individual/en/products/251882/), fund product ID `251882`. Historical `asOfDate=20151231`, `20201231`, `20240630`, `20261030` should be tested against the relevant original UK fund AJAX URL and actual portfolio rows/date, not assumed to work because US history does. Older source data, original investment schedules and EU-specific endpoint behavior are **unverified**. A functioning 2015 SWDA download would materially improve that target; returns with latest holdings despite old `asOfDate` must be rejected.
- [Vanguard VT](https://advisors.vanguard.com/investments/products/vt/vanguard-total-world-stock-etf) actively lists **12 historical month-end holdings dates** through 2025–26 and an Export full holdings control; SEC original N-CSR/N-Q/N-PORT covers older fund reports. This gives a robust **fund** holdings population, not MSCI/FTSE official weight universe.
- [TickerInside quarterly](https://tickerinside.com/api/) provides pre-parsed US SEC N-PORT top-ten full quarterly issuer concentration since 2019 and dated holdings JSON; the site's separate daily history began **September 2026**, so do not confuse them. [ORTEX documented date-selected holdings API](https://docs.ortex.com/reference/etf_holdings_retrieve) provides a `TEST` trial key, but the historical date/region coverage is constrained.

### 3. Multinational profits: high-coverage **free browser views**, limited bulk

- [FinancialFilings](https://financialfilings.com/) public site indexes **~54 million original filings** for roughly **93,000 issuers in ~60 markets** according to the site's current displayed counts, and offers **free browse/search and Markdown export** plus a free **MCP** discovery client. Standardized issuer financial statement views are public. Its **REST API/bulk exports are paid**, although a monthly free credit offer is advertised; no evidence of free complete historical global bulk download. For the user who prioritizes publicly visible data, this is an excellent *company discovery and schema cross-validation* candidate; direct filing source identities must be retained.
- [ROIC.ai](https://www.roic.ai/api) advertises original 68,000+ company fundamentals across 70+ exchanges, with a no-card **free API limited to 5 requests/minute and two years of statements**. The visible [ROIC.ai bulk catalog](https://www.roic.ai/api/docs/bulk/fundamentals) reaches back into the 1980s, but **Pro/Enterprise payment is required to download bulk files**; a visible list is not the same thing as free bulk access. Never report bulk historical world company financials as solved just because a CSV list exists.
- For **actual long-history originals**, SEC XBRL, ESEF, Brazil CVM, Korea OpenDART, Taiwan open CSV, Japan EDINET and the Indian NSE filing pages remain superior primary raw sources. Multi-market issuer-level financials can be studied free via web; **complete comparable global consolidated parent profits** with historical coverage, deduplication, IFRS/GAAP reconciliation remains research-unresolved.

### 4. Global stocks/bonds index returns

- The public MSCI `getLevelDataForGraph` route is the strongest new lead for **actual MSCI ACWI historical USD NETR**, subject to live spot-checks and data availability. Official [MSCI ACWI page](https://www.msci.com/indexes/index/892400/msci-acwi-index) confirms code `892400`; [CFA member datasets](https://rpc.cfainstitute.org/msci) are not necessary if that endpoint serves the required full monthly NETR levels.
- Bloomberg originally labels the Global Aggregate USD unhedged **`LEGATRUU`** (official [Global Aggregate Index Methodology](https://assets.bbhub.io/professional/sites/27/Global-Aggregate-Index.pdf)), created 1998 with **backfilled history to January 1990**. [Bloomberg public rate/bond table](https://www.bloomberg.com/markets/rates-bonds) displays a current `LEGATRUU:IND` level, and issuer fund pages (e.g. [Amundi Global Aggregate Bond](https://www.amundietf.nl/en/professional/products/fixed-income/amundi-core-global-aggregate-bond-ucits-etf-acc/lu1437024729) and [iShares AGGG](https://www.ishares.com/uk/individual/en/products/291773/)) identify and expose benchmark levels and historical returns. **No verified no-login 1990–2026 continuous `LEGATRUU` daily/monthly download yet**, so this original index benchmark remains a targeted search.
- [justETF historical data tracker](https://github.com/DeBenez/just-etf-data-tracker) documents historical UCITS fund monthly return retrieval by ISIN and optional total-return price fields. This is an actual **fund return** method, not Bloomberg's own original historical index.
- [Independent GEM monthly USD return dataset](https://github.com/Petitmarius/Backtest_Strategies/blob/main/data/README.md) covers **1969-12–2026-07** for US, ex-US equities, US aggregate bonds and bills, with [source splice provenance](https://github.com/Petitmarius/Backtest_Strategies/blob/main/data/SOURCES.md). It includes **US Aggregate** bonds, **not Bloomberg Global Aggregate**. Useful for historical contextual controls if splices are audited; not an original index.
- [Bloomberg index level official current public page](https://www.bloomberg.com/markets/rates-bonds) and [YCharts annual `^BBGATR`](https://ycharts.com/indices/%5EBBGATR) show current and annual return snapshots. These do not establish the daily/monthly original level record.
- [iShares AGGG fund](https://www.ishares.com/uk/individual/en/products/291773/) launched **21 November 2017**. Its fund performance can provide **2017–present fund total returns** with separate distribution accounting; it is not original `LEGATRUU` and cannot cover the preceding 1990–2017 bond history by itself.

## Original-source accessibility gate (new protocol)

First evaluate **can the historical values be obtained through normal public browsing, a documented unauthenticated endpoint, a no-fee public API account, published original downloadable filings, or an existing open repository?** Record endpoint/query, original variables, sample dates and response structure, actual time extent, source-revision/filing dates. Then separately record authentication/payment and any published restrictions. A public route with terms restrictions remains a technical candidate in the search report instead of being discarded solely because of those terms. Never claim actual verified raw data without retrieving a real sample. Do not conflate publicly accessible output with permission to redistribute or evade genuine paid access controls.
