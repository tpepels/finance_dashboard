The user specifically requested to research lower-frequency/narrower alternatives *before development*, to avoid reopening source-method discussions when a provider endpoint fails.

## Data maturity vocabulary

- **R0 — Original verified file/data row:** source download or GitHub file was actually inspected, with schema, first/last observations, concept and known data gaps. This verifies **sample availability only**, not historical completeness or broad scientific validity.
- **R1 — Original publisher dated evidence:** official filing index, PDF report, data-explorer series or country-period source page inspected; full historical data rows/complete API retrieval not audited.
- **R2 — Documented reachable candidate:** provider/tool documents an endpoint/frequency but exact historical request and response have **not** been tested.
- **R3 — Constructed research alternative:** genuine reproducible estimate with a different observation population, return convention or market universe; must be named explicitly as a *research estimate*, no exact index identity.
- **OPEN — exact target:** complete original history remains unverified. An R0 alternative does not magically upgrade an OPEN original to verified.

**Unit of fallback** is a named scientific *view*, not an anonymous swap of a dataset inside the same statistic. Each display exposes source class R0/R1/R2, universe, frequency, years, observation/report/first-publication dates, formula, limits and missing data. No synthetic historical point is shown as original. An unavailable source must never suppress the research question when a legitimate narrower comparison still answers a named subset of it. Never splice disparate index and fund sources into a single unlabeled long history.

**Fallback decision rules for portfolio research:**
- For **recent real-investable fund diversification (2018+)**, compare original published fund NAV total returns **VT vs BNDW vs gold fund or bullion spot**, precisely labelled *USD-hedged world bond fund* and true gold return convention; use matched dates.
- For **fuller 1990–2022 historical monthly research**, use **Kenneth French developed-market equities + Swinkels source sovereign-bond series + World Bank gold spot**, matching USD/country and publishing original versus modelled semantics; **do not** claim ACWI/Bloomberg original indexes.
- For **2013–2018 recent international bonds**, use **BND+BNDX reconstructed mix**, clearly marking US and ex-US hedge conventions and assumed weights; compare with BNDW only over their mutual history to check validity.
- For **very long annual stress histories**, use **JST** with its declared advanced-economy sample; use **ICE original global bond annual returns 2015–2024** for an independent annual global bond reference.
- Never splice annual ICE, academic sovereign, BNDW, BND+BNDX, NETR or US Aggregate returns into one unnamed history. A multiple-line comparison may show clearly labelled distinct sample periods.

## Ex ante acceptance and no-research-repeat rules

For **every future planned graph** the source choice is a **versioned ordered set**: exact original (if verified) → approved published lower-frequency original → statistically described narrower original → openly labelled published academic/research construction. The switch is triggered by **observed API unavailability, missing dates, material source-method mismatch, or uncovered geography**, never by a desired particular numeric result.

Minimum source-specific checks before use: (1) exact original identity/ISIN/index code/issuer, (2) one early and one late real row, (3) original observation versus filing availability/revision, (4) source unit/frequency and return/price/holding convention, (5) denominator reconciliation or missingness, (6) source method and version and whether back-cast, (7) no false continuity when changing source/frequency, (8) original-source terms recorded separately from **technical fetch ability** without using them to filter the initial candidate search. Degraded/partial data must be explicitly visible.

**No user reapproval needed merely to choose a lower-resolution scientific view that is already defined here**, but a source that changes the **economic question** must be presented as a separately titled analysis, not quietly substituted for an owner-approved G01, G03 or P02 original. Full Phase 1 methodological integration and actual data/source verification are *still open*. All dataset implementation and code gap analysis remain paused.
