# Missing economic indicators and full implementation plan

**Repository audit: 2026-11-03.** This tracker distinguishes (A) a research quantity not actually measured in the present backend, (B) a registered proxy/definition that is narrower than the requested original, and (C) a quantity whose code exists but real local evidence is missing or not yet accepted.

**Baseline:** `definitions/series.json` has 53 mapped canonical macro series; `research.py` has 46 configured research cards (12 World/OECD, 14 US, 6 Europe, 6 Japan, 8 comparisons). `market.py` independently registers 24 market instruments. A mapping is **not** proof of imported data. Earlier isolated full-source backend acceptance and the currently deployed server are different verification environments.

## Ordered implementation work, whole-scope acceptance

1. **Source coverage census and ingestion repair.** Build a single auditable source-readiness report across all 53 source contracts plus the 24 market instruments/3 FX feeds. Display only missing/stale statuses in the primary UI; a full evidence table stays in the on-page source explorer. Resolve Germany/France/Italy source ingestion, refresh errors, and genuine ALFRED as-of access. Acceptance: every source has validated nonempty history or a source-specific, non-ambiguous blockage, never an unexplained `no_data`.
2. **Complete historical collection.** Backfill ALFRED and date-stamped SEC N-PORT identities with resumability, source hashes, release/eligibility metadata, no lost older data and independent source spot checks. Broaden SEC mapping to all named US ETFs, then create separate UCITS historical reporting importer. Acceptance: recorded date/coverage audits and no unsupported ETF look-through.
3. **Complete the original macro research comparisons.** Source harmonized hours/compensation, reconstruct global credit stock/GDP and audit BEA Q / gold–MSCI source returns. Implement sensitivity and coverage dashboards alongside date-joined charts. Acceptance: numerator/denominator unit tests and independent recomputation of source examples; mismatched geographic scope never presented as a world statistic.
4. **Resolve licensed global securities data.** Obtain real licensed MSCI monthly constituent history and global issuer consolidated earnings, clear reuse rights, implement stable issuer and security identity crosswalks, process source vintages and FX. No free proxy can fulfill those originals. Acceptance: complete month/year coverage and reconciled weights/consolidated earnings; if license cannot be obtained, keep explicit blocked state and retain approved sparse / EU27 / OECD substitutions without claiming exact fulfillment.
5. **Research-grade value-added and profit-rate accounting.** Audit original OECD IOT archive, independent net capital stock, and theoretical sector/turnover assumptions; implement identities, scenario sensitivity, cross-country robustness and provenance. Acceptance: no quantitative Marxian rate without complete matched originals and explicit assumptions.
6. **Prospective research validation.** Backtest against historically available snapshots, event-independent and forward holdouts, uncertainty intervals, baseline models and costs for any portfolio scenario. No "crash risk" numeric composite until externally defensible. Acceptance: documented out-of-sample result and limitations, not unit test simulations.
7. **Full acceptance / data-loss audit.** Short deterministic Python and frontend tests, Docker build, user-browser inspection (desktop/mobile × dark/light), source-by-source count/date proof, verified on-disk original-source archives and copy of backup manifests to a second device. Acceptance: close no phase while source coverage, chart legibility or externally required evidence remains unverified.

**Operating rule:** In the single-page application, only current indicator/chart, unit/date and concise status are primary. Comparative charts and short interpretations are secondary. All formulas, original source details, publication-vintage qualifications and extensive methodology belong in user-opened disclosures, not above the first plot.
